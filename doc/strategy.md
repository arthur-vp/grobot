
1. Strategie
Robot commencent dos à dos

Soit :
- Avance de 5CM pour se séparer
- Retourne à 180° pour se faire face

Soit :
- Recule fort d'un coup pour tej l'ennemi
- Puis se retourne à 180° pour se faire face


Ensuite :

Recherche de l'ennemi avec un capteur de distance
- Si l'ennemi est détecté, rotation puis avance vers lui
- Si l'ennemi est à portée de tir, tir
- Sinon rotation de 90° à gauche ou à droite
